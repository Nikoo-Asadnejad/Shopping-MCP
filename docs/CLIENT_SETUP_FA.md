# راهنمای فارسی Shopping MCP

این سرویس مستقل و غیررسمی، اطلاعات فعلی دیجی‌کالا را فقط می‌خواند. ورود به حساب، سبد خرید، پرداخت و ثبت سفارش ندارد. قیمت‌ها به تومان هستند و هزینه ارسال، اگر مشخص نباشد، نامعلوم اعلام می‌شود. پیش از خرید، لینک مستقیم کالا را بررسی کنید.

## اتصال محلی

با Python نسخه 3.12 یا بالاتر و ابزار `uv`:

```bash
uv sync --locked
uv run shopping-mcp
```

برای کلاینتی که سرور را اجرا می‌کند، تنظیمات `mcpServers` و مسیرهای کامل را از [راهنمای اتصال](CLIENT_SETUP.md) بردارید. برای اتصال HTTP محلی:

```bash
uv run shopping-mcp --transport http --host 127.0.0.1 --port 8000
```

آدرس اتصال `http://127.0.0.1:8000/mcp` است. مسیر `/health` زنده بودن سرویس را نشان می‌دهد؛ مسیر `/health/digikala` دسترسی به جست‌وجوی دیجی‌کالا را بررسی می‌کند (۲۰۰ برای موفقیت و ۵۰۳ برای خطا، با کش ۳۰ ثانیه‌ای)؛ مسیر `/privacy` توضیح حریم خصوصی است.

## اتصال در ChatGPT

ابتدا باید سرویس روی میزبان واقعی با HTTPS راه‌اندازی و دسترسی آن به دیجی‌کالا تأیید شود. هنوز آدرس عمومی تأییدشده‌ای برای این پروژه ثبت نشده است.

طبق [راهنمای رسمی OpenAI](https://developers.openai.com/plugins/quickstart)، اتصال از مسیر Plugins و گزینه Add custom MCP server انجام می‌شود. آدرس عمومی شامل `/mcp` را وارد کنید، نام اتصال را تعیین کنید و تنظیمات احراز هویت میزبان را اعمال کنید. پس از ساخت و نصب افزونه، در گفت‌وگوی Work با `@` آن را انتخاب کنید. [راهنمای تست اتصال](https://developers.openai.com/plugins/deploy/connect-chatgpt) محدودیت‌های حساب و فضای کاری را نیز توضیح می‌دهد.

اگر میزبان توکن دارد، کلاینت باید ارسال هدر Bearer را پشتیبانی کند؛ این نسخه ورود OAuth ندارد. نبودن توکن روی میزبان به معنای اتصال بدون احراز هویت است. توکن را در متن گفت‌وگو یا مخزن قرار ندهید.

این مراحل مستندات مسیر وب هستند. وجود گزینه‌ها و کارکرد مسیر روی حساب و تلفن موردنظر در ایران هنوز آزمایش نشده است. پس از تأیید اتصال وب، همان شش درخواست را روی تلفن امتحان کنید و زمان پاسخ معمولی و اولین پاسخ پس از بی‌کاری میزبان را ثبت کنید.

## نمونه درخواست‌ها

- «لپ‌تاپ‌های موجود تا ۴۰ میلیون تومان را پیدا کن و لینک بده.»
- «مشخصات و فروشندگان این لینک کالا را بررسی کن.»
- «این دو کالا را از نظر قیمت، رم، حافظه و فروشنده مقایسه کن.»
- «نظر خریداران این کالا را خلاصه کن و بگو چند نظر بررسی شده است.»
- «با این بودجه و حداقل ۱۶ گیگابایت رم، گزینه اقتصادی و گزینه با شواهد رضایت بیشتر را پیشنهاد بده.»
- «برای این عبارت ناقص، پیشنهاد جست‌وجو بده.»

برای پیشنهاد خرید، اگر چند دسته ممکن باشد، دستیار باید دسته مناسب را از شما بپرسد. ویژگی‌های ضروری فقط با عبارت موجود در مشخصات تأیید می‌شوند؛ نبودن یک ویژگی در داده، اثبات وجود آن نیست. پیشنهادها از نمونه محدود کالاها و نظرات ساخته می‌شوند و همه بازار را پوشش نمی‌دهند.

خطای `rate_limited` یعنی باید کمی بعد دوباره امتحان کنید. خطای `unavailable` یعنی سرویس فروشگاه فعلاً در دسترس نیست؛ در این وضعیت می‌توانید لینک مستقیم دیجی‌کالا را باز کنید. اطلاعات شخصی یا حساس را در جست‌وجو وارد نکنید. راهنمای استقرار و وضعیت پذیرش در [DEPLOYMENT.md](DEPLOYMENT.md) و [PHASE_0.md](PHASE_0.md) آمده است.
